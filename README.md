# 인적성 시험 도우미

Windows에서 문제 창 옆에 놓고 쓰는 오프라인 시험 보조 프로그램입니다. API, 로그인, 별도 사용료가 없습니다.

## 실행

1. 저장소의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. Python 3.10 이상(공식 Windows 설치본, Tcl/Tk 포함)을 설치합니다.
3. `start.bat`를 더블 클릭합니다. 또는 `python app.py`를 실행합니다.

외부 Python 패키지는 필요하지 않습니다. 같은 `app.py`가 macOS에서도 실행됩니다(맥 전용 글꼴·트랙패드 스크롤·Cmd+Q 저장 포함). EXE 빌드는 아래 GitHub Actions에서 제공합니다. 빌드가 성공하면 Actions → Build Windows app → Artifacts의 `aptitude-companion-windows`를 받아 압축을 풀고 EXE를 실행할 수 있습니다.

## 사용

- 왼쪽 문제 창은 직접 엽니다. 이 프로그램을 화면 오른쪽으로 이동하세요.
- 맨 위 타이머 막대, 답안지의 제목·회차·버튼 줄은 고정되어 있고 과목 선택과 20문항만 스크롤됩니다.
- 제목과 회차를 입력하고 과목 선택 상자로 전환합니다.
- 순서: 언어이해 → 자료해석 → 창의수리 → 언어추리 → 수열추리. 각각 20문항, 5지선다입니다.
- 각 문항 하나의 선택지, `해제`로 미응답 전환. 과목 전환 시 답안과 메모가 유지됩니다.
- 과목별 15분 타이머: `시작`을 누르면 카운트다운하고 마지막 1분은 빨간색으로 표시됩니다. 과목을 바꾸면 새 과목은 15:00부터 다시 시작합니다(진행 중이던 타이머는 취소).
- 시간이 끝나면 “시간이 종료되었습니다” 알림과 함께 그 과목의 답안 선택이 잠기고, 임시 기록과 엑셀 파일이 대화 상자 없이 자동 저장됩니다(제목이 없으면 엑셀 저장은 건너뜀). 잠금은 프로그램을 다시 켜도 유지되며 `답안 저장`을 직접 누르면 풀립니다. 메모는 잠기지 않습니다.
- 두 구분선을 드래그해 세 영역 높이를 조절합니다. 각 영역의 최소 높이를 보장하며, 답안지/계산기는 내부 스크롤, 메모는 줄바꿈과 독립 스크롤을 사용합니다.
- 기본 최소 크기는 360×540이며, 높은 글자 배율에서는 실제 버튼·글자 크기에 맞춰 최소 너비와 영역 높이가 자동으로 커집니다. 3개 영역을 동시에 사용할 수 있는 크기를 유지합니다. Windows 배율과 작업 표시줄 때문에 공간이 부족하면 디스플레이 설정을 조절하세요.
- 계산기 입력칸에서 Enter로 계산, Esc로 지우기. 사칙연산, 괄호, 소수점을 지원합니다.
- `답안 저장` 첫 사용 시 폴더를 선택합니다. 이후 위치를 기억하며 `위치 변경`으로 바꿀 수 있습니다.
- `폴더 열기`로 탐색기를 열어 엑셀 답안(xlsx)과 정답표 사진을 같은 ChatGPT 채팅에 첨부하세요.
- `프롬프트 복사`로 첫 채팅에 지침을 붙여넣습니다. 이후 “이번 시험 채점하고 누적 기록 갱신해줘”라고 요청합니다.
- 성적 채점과 추이는 ChatGPT에서 관리합니다. 프로그램 내부 채점/API/성적 그래프/결과 가져오기는 포함하지 않습니다.

## 저장과 개인정보

- 답안은 `제목_회차.xlsx` 엑셀 파일 하나로 저장합니다(기존 TXT 저장을 대체). 과목마다 탭이 하나씩 있고 A열 문항, B열 내 답(빈칸은 미응답), C열 정답, D열 결과입니다. 탭 아래쪽에 정답 수·오답 수·미응답 수식, 시간 종료 여부, 과목 메모, 저장 일시, 시험 제목, 회차, 응시 일시, 시험 식별번호가 들어갑니다.
- C열에 정답을 입력하면 D열에 O/X/미응답과 정답 수·오답 수가 자동 계산됩니다. 같은 시험을 다시 저장해도 C열에 입력한 정답은 유지되며, C열 외에 엑셀에서 직접 고친 내용은 다시 저장할 때 앱의 답안·메모로 덮어씁니다.
- 같은 시험(같은 시험 식별번호)은 항상 같은 파일을 갱신합니다. 제목·회차는 같지만 다른 시험이면 `_2`, `_3`을 붙여 별도 파일로 저장합니다. 앱의 답안 파일로 읽을 수 없는 같은 이름의 파일은 덮어쓰지 않고 다음 번호로 저장합니다.
- Windows에서는 엑셀로 열어 둔 파일에 저장할 수 없습니다. 저장 실패 알림이 나오면 엑셀에서 파일을 닫고 다시 `답안 저장`을 누르세요. 파일은 완전히 쓴 뒤 교체하므로 실패해도 기존 파일은 그대로 남습니다.
- 편집 후 0.45초에 임시 저장하고 정상 종료 시 즉시 저장합니다. 강제 종료 직전 입력은 잃을 수 있습니다.
- 임시 기록/설정: Windows `%LOCALAPPDATA%\AptitudeCompanion`, macOS `~/Library/Application Support/AptitudeCompanion`. 새 시험 시작 전 JSON 원본은 `archives`에 보관합니다.
- 앱은 답안이나 사진을 네트워크로 전송하지 않습니다. 사용자가 직접 ChatGPT에 첨부합니다.

## 개발 검증

`python -m unittest -v` — 엑셀 100문항 내보내기, 정답(C열) 보존, 같은 제목·회차 파일 선택, 원자적 교체, 저장/복원, 데이터 검증, 계산기 안전성.
`python ui_check.py` — 그래픽 디스플레이가 필요하며 창 크기/분할 경계/과목 전환/타이머 잠금을 검증합니다.

Windows EXE는 GitHub Actions의 Windows 러너에서 PyInstaller로 빌드합니다. 실제 Windows의 배율별 사용감과 탐색기 실행은 사용자 PC에서 최종 확인이 필요합니다.

## 디스플레이 회귀 검사

Windows 러너에서 1920×1080 및 2880×1800 화면 정보를 모사하고 Tk 글자 배율 100/125/150/200%를 적용해 검사합니다. 8개 조합 × 창 크기 4개 × 분할 위치 3개 = 96개 배치에서 영역 경계, 타이머 막대·고정 헤더·내부 버튼/글자 잘림, 끝까지 스크롤 가능 여부를 확인합니다. 과목별 입력 보존 및 재실행 복원, 시간 종료 시 과목 잠금·엑셀 자동 저장·재실행 후 잠금 유지·수동 저장 시 해제도 검사합니다.

이 검사는 물리 모니터 해상도를 변경하거나 Windows 디스플레이 배율을 직접 전환하는 검사가 아닙니다. 실제 다중 모니터 이동 및 OS 배율 변경은 별도 실기 확인이 필요합니다.
